# 研究笔记

按研究线存放可复用结论。有价值的 notebook 结论提炼到这里，不把
`notebooks/` 当长期依据。

- [A 股股债利差的利率锚](erp-rate-anchor.md)：美元口径的优势来自哪里；中国实际利率口径。
- [利率锚阶段性报告](erp-rate-anchor-interim-report.md)：供外部评审的阶段总结与待答问题。
- [第二阶段计划](erp-phase2-plan.md)：P0 max 归因与 P1 估值因子稳健性的事先方案。
- [报告一：max 口径超额收益归因](erp-max-attribution.md)：优势来自 2022 年一次切换与仓位规则，安慰剂下不显著。
- [报告二：估值因子统计稳健性](erp-valuation-robustness.md)：没有变量达到样本外证据；V 为样本内证据，依赖训练起点。
- [报告三：下一阶段设计](erp-next-stage-design.md)：冻结口径做前瞻记录、仓位映射、估值陷阱；暂不做 A/H 与全球因子。
- [第三阶段计划](erp-p4-plan.md)：冻结候选口径、仓位映射与风格指数复核的事先方案。
- [报告四：仓位映射与价值、成长指数复核](erp-position-mapping.md)：没有普遍更好的映射；结论只在中证全指成立，创业板指上美元口径领先。
- [第四阶段计划](erp-phase4-plan.md)：红利股息率口径与成长风格全球利率敏感度的事先方案。
- [报告五：红利股息率与成长风格的全球利率敏感度](erp-dividend-growth.md)：股息率口径不更好；300 成长相对价值对美国实际利率显著敏感，对汇率不敏感。
- [第五阶段计划](erp-phase5-plan.md)：实际利率预测风格价差；区分久期渠道与全球成长风格同步的事先方案。
- [报告六：美国实际利率能否预测风格价差](erp-style-predict.md)：不能，只有同期关系；不可做月度轮动。
