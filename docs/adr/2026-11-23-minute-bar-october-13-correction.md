# 2026-10-13 分钟行情两条负成交量修正

MySQL `m20261013` 有三条 15:00 负成交额记录：

- `920069.BJ` 成交量 -1 手、成交额 -44 元
- `920080.BJ` 成交量 -1 手、成交额 -41 元
- `920541.BJ` 成交量 0、成交额 -54 元

前两条是既往同类「收盘分钟 -1 手」异常，按负责人惯例指示把成交量置 0，成交额
仍须通过日行情对比（负值置 0 后分钟成交额合计与同日日行情成交额统一换算为元后
差异严格小于 0.5%）才置 0 入库，否则排除该股票当天全部分钟数据并停止入库。
第三条成交量本就是 0、不属于该裁定范围，只由既有日行情对比规则处理。

写前核对唯一记录及原值，源值变化即停止；不修改 MySQL。运行日志记录源摘要及
修正前后值。
