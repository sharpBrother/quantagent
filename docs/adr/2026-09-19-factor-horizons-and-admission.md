# 因子多周期检验与三层准入

## 背景

继承旧仓股票与 ETF 因子检验经验：单一预测周期表现差，不能推断其他周期
无效；研究有效、适合展示和适合组合是三个不同判断。2026-09-19 项目负责人
确认本轮只固化原则，并允许非主周期通过的因子进入 Website。

## 决策

1. **股票主协议保持 `oo_5d`**，预注册检验集合包含 1D、5D、10D、20D。
   每个周期必须绑定对应的真实 forward return label，不能复用、缩放 5D
   收益或只改标签名称。分别判断成熟日与可用样本；未成熟和缺失不填充。
2. **逐周期独立报告** IC、ICIR、RankIC、G10-G1、单调性、覆盖率和显著性，
   同时保留样本范围、数量、稳定性证据、失败与不可计算原因。因子回看窗口、
   指标统计窗口、预测周期、组合调仓周期必须分开表达。
3. **先登记、后检验**：记录检验家族、全部候选因子/参数/周期、实际检验范围、
   检验数量与多重检验方法。显著性判定须考虑多重检验和跨日收益重叠；完整
   披露全部预注册周期的结果，不能只挑最优周期或事后改主周期。
4. **三层状态独立记录，并保留原因及证据身份**：

   | 层次 | 准入要求 |
   |---|---|
   | 研究筛选 | 至少一个预注册周期通过统计（含多重检验处理）、PIT、覆盖率与稳定性要求 |
   | Website 展示 | 研究证据合格，明确列入展示名单，当前所需数据完整，展示 horizon / protocol 身份完整 |
   | 组合准入 | Website/研究合格，且与现有因子冗余可接受、有边际贡献、权重 PIT 正确，换手、成本、容量通过 |

   上一层通过不自动使下一层通过；尚未评估或证据不足必须显式呈现。
5. **Website 必须显示 `primary_horizon` 和 `protocol_id`**，另行标明研究
   通过周期及其协议身份，保留全部周期结果与 `pit_report`。例如 5D 未通过、
   10D 通过时，满足展示条件即可展示；明确写出这两个结果，主周期仍为 5D。
   “当前数据完整”按各周期应成熟的标签判断，不要求最新截面已有未来收益。
6. **ETF 复用多周期证据与三层状态原则**，不复制平行评价链路；本决策不把
   股票 `oo_5d`、周期集合或股票覆盖率门槛直接套给 ETF。

## 理由

保留主协议保证可比性，完整多周期证据避免漏掉期限差异；独立准入状态避免
把统计有效或页面展示误当作可投资性证明。

## 被否方案

仅凭 5D 否定因子、挑最优周期替换主协议、用 5D 收益冒充其他标签，以及研究
通过就自动展示或入组合，分别破坏研究边界、检验有效性或执行证据要求。

## 代价

需维护多套真实标签及逐周期证据，披露更多负面结果；较长周期的成熟数据更滞后。

## 推论与实施边界

这是已裁定、待实现的要求，不表示标签、评价或 Website 已贯通。本轮不修改
代码、Protocol、schema、visibility 或产物，也不运行研究或写库。实施前需明确
收益腿及交易日端点与现有身份的绑定、统计与稳定性阈值、多重检验家族和方法、
ETF 周期计划；未明确项不得由实现自行选定。所有晋级仍为研究用途，不授权交易。
