# event_aog 迁移口径

## 背景

`event_aog`（盈余公告开盘跳空，`pf_single_event_aog_1_mean_pos`，方向 +1）迁移自旧仓
`factors/factor_event_2.py`。定义：个股盈余公告次日开盘涨幅 − 中证 500 指数次日开盘涨幅。
它是事件因子中**唯一依赖行情**的，带来了四个 event_sue 没有的新问题。

## 决策

### 1. event_dt = open_date，非 declare_date（下游证据驱动）

因子值 = 个股夜盘涨幅(open_date) − 指数夜盘涨幅(open_date)，描述的是 open_date 的开盘跳空，
且**依赖 open_date 行情才能算出**。下游 `alpha_factory/etf/gateway.py` 注释明确：
"event_* 的 effective date 是 confirm_date"，而 aog 的 `confirm_date = open_date`（旧代码）。
故 `event_dt = open_date`，`knowledge_dt` 箍到 open_date。若错用 declare_date 作 event_dt，
会在开盘前前视未知的开盘涨幅。实证：2026-10-31（周六）declare、2026-11-02（周一）open，
event_dt=2026-11-02。这与 event_sue/event_delta_roe 的 `event_dt=declare_date` 根本不同
（它们不依赖行情）。

### 2. 开盘日判定沿用旧仓 entrytime（2026-11-26 裁定）

`entrytime`（带时分秒的入库时刻）判开盘日：`entrytime < declare_date`（前一晚已入库）或
同日 `%H%M <= '0925'`（集合竞价 9:25 结束前入库）→ 公告**当日**首个交易日；否则 → 公告
**次日**首个交易日。`entrytime` 在此的角色是**市场微观结构建模**（开盘价何时消化财报），
**不是** PIT 可见性字段（事件候选的可见性截止仍是 declare_date，grade A）——两者职责不同。
三源 entrytime 全量非空（已实证）。

### 3. 域判定在 open_date（裁定 A1）+ 非交易日覆盖

财报可在任意自然日 declare（周末/节假日是披露高峰，wx2 19.5% 事件行来自非交易日 declare），
非交易日无 all_a/ST 截面。aog 描述 open_date 的市场反应，股票须在 open_date 是域内可交易
股票才有意义，且 open_date 必是交易日——故域判定在 open_date。这让非交易日 declare 的事件
正确落入下一交易日 open_date，**无覆盖缺口**（区别于 event_sue 初版的 19% 缺口）。
全湖验证：**非交易日 event_dt 行数 = 0**（因 event_dt=open_date 必是交易日），正确。

### 4. 跨月分区修复：按 event_dt 过滤 + declare 向前宽限

aog 的 open_date = declare 后首个交易日，月末 declare 的 open_date 跨到下月——event_dt 与
declare 读取窗口不同月。初版逐月物化时，201802 把 694 行 open_date=2018-03-01 的行错写进
ym=201803，导致 201803 物化冲突。修复：declare 读取窗口**向前宽限 10 天**（覆盖上月末
declare、open_date 在本月的事件），写入前**按 event_dt 过滤到 [start,end] 本月**——本月末
declare、open_date 跨到下月的行丢弃由下月写入。每个事件恰好被一个月份写入（open_date 决定
分区），ym 分区不重叠。抽查 ym=201802/201803/202203/202207 的 event_dt 全部在本月，零跨界。

### 5. 夜盘涨幅从源重算，不建 stock_ratio 镜像

旧仓 `stock_ratio.night_ratio` 是派生表（`wind_to_sql_2.py`：`100*(S_DQ_ADJOPEN/S_DQ_ADJPRECLOSE-1)`）。
新仓直接从 `ASHAREEODPRICES` 重算：个股 `100*(adj_open/adj_preclose-1)`（复权，避免分红除权
假跳空）、指数中证500 `100*(S_DQ_OPEN/S_DQ_PRECLOSE-1)`（`AINDEXEODPRICES`，不复权）。
实证与 wx2 `stock_ratio.night_ratio` 差异 < 5e-5（wx2 存储舍入）。窄扩展 `IndexReturn`
加 `open`/`preclose`（S_DQ_OPEN/S_DQ_PRECLOSE）；`DailyPrice` 已有 `adj_open`/`adj_preclose`。

## golden 对拍结果

fixture `tests/golden/market_data/event_aog/20240429.json`（wx2 confirm=20240429 逐 report_period
行 2302 行）。选 2024-04-29（周一）因覆盖**非交易日 declare** 关键场景：2302 行来自三个
declare 日——20240427 周六（1627 行，70%）、20240429 周一（667 行）、20240426 周五（8 行）。
**1569 只股票 100% 严格一致**（match=1569 diff=0 missing=0）。event_aog 纯行情计算、不依赖
历史财报序列，无 event_sue/event_delta_roe 的财报修订快照时差，故零差异。测试断言零缺失零不一致。
