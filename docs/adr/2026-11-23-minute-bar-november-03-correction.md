# 2026-11-03 分钟行情两条负成交量修正

MySQL `m20261103` 有三条 15:00 负成交额记录：

- `920275.BJ` 成交量 -1 手、成交额 -35 元
- `920931.BJ` 成交量 -1 手、成交额 263 元
- `920030.BJ` 成交量 0、成交额 -55 元

前两条是既往同类「收盘分钟 -1 手」异常，按负责人惯例指示成交量和成交额均置 0。
其中 `920275.BJ` 的成交额为负，仍须通过日行情对比（负值置 0 后分钟成交额合计与
同日日行情成交额统一换算为元后差异严格小于 0.5%），不达标即排除该股票当天全部
分钟数据并停止入库。第三条成交量本就是 0、不属于该裁定范围，只由既有日行情对比
规则处理。

写前核对唯一记录及原值，源值变化即停止；不修改 MySQL。运行日志记录源摘要及
修正前后值。
